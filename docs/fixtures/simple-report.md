# Fixture Spec: simple-report

## Purpose
Validate baseline retention for ordinary prose documents.

## Required elements
- title
- heading levels 1-3
- normal paragraphs
- bold / italic / underline samples
- ordered and unordered lists
- explicit page break
- short concluding paragraph

## Evaluation focus
- text preservation
- heading hierarchy
- paragraph segmentation
- list continuity
- basic inline emphasis

## Failure examples
- heading flattening
- paragraph merge/split drift
- list numbering reset
- lost emphasis
