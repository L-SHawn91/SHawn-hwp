# Fixture Spec: submission-template

## Purpose
Simulate institution-facing document packaging and submission review.

## Required elements
- cover/title block
- body with section hierarchy
- at least one table
- at least one figure with caption
- page break
- footer or page numbering if available
- final declaration / closing section

## Evaluation focus
- overall submission readability
- page setup stability
- spacing consistency
- table/figure usability
- print/PDF sanity

## Failure examples
- page margins drift severely
- page numbering breaks
- sections collapse into each other
- figure/table positioning becomes unusable
