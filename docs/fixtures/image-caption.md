# Fixture Spec: image-caption

## Purpose
Validate handling of embedded images and nearby captions.

## Required elements
- at least 2 embedded images
- captions under each image
- surrounding explanatory text
- one resized image
- one image placed between section text blocks

## Evaluation focus
- image presence
- image order
- caption linkage
- scaling anomalies
- surrounding paragraph continuity

## Failure examples
- missing images
- captions moved to wrong image
- oversized image rendering
- image order inversion
