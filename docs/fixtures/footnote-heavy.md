# Fixture Spec: footnote-heavy

## Purpose
Check note-anchor stability and note body preservation.

## Required elements
- multiple footnotes across sections
- repeated footnotes in close proximity
- paragraph with 2+ note anchors
- note text with mixed punctuation and citation-like content

## Evaluation focus
- note count
- note anchor placement
- note text completeness
- note numbering continuity

## Failure examples
- dropped notes
- anchor drift
- note renumbering errors
- note text truncation
