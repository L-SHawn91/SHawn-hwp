# Fixture Spec: table-heavy

## Purpose
Stress-test table preservation and submission usability.

## Required elements
- simple table
- merged cells
- multiline cell text
- numeric columns
- table caption
- table followed by explanatory paragraph

## Evaluation focus
- table count consistency
- row/column consistency
- merged-cell integrity
- cell text stability
- caption attachment

## Failure examples
- merged cells broken apart
- row shifts
- text moved to wrong cells
- caption detached from table
