# Vision

SHawn-hwp is built to outperform unsatisfying document conversion tools by focusing on quality, transparency, and reproducibility.

Its real target is not generic office conversion. Its main target is reliable movement between `hwp/hwpx` and `docx/markdown`, with practical return paths back into the HWP/HWPX ecosystem.

The project does not define success as file generation alone. It defines success as controlled, explainable, and reviewable conversion.
