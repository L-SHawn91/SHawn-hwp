# SHawn-hwp

Use this skill for document conversion tasks involving HWP/HWPX, DOCX, and Markdown, especially when quality, round-trip stability, and submission readiness matter. Also use it for Korean research proposal authoring workflows where structured content must be validated before injection into an official HWP/HWPX template.

## Core rules

1. Preserve originals.
2. Prefer reproducible workflows.
3. Do not treat file generation as sufficient proof of quality.
4. Report likely loss points explicitly.
5. Distinguish working-draft, edit-ready, and submission-ready quality.
6. For research proposals, validate required content sections before attempting HWPX template injection.
7. Treat official HWP/HWPX templates as protected layout assets; generate derivatives only.
