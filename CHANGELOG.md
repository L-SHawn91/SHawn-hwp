# Changelog

All notable public changes to SHawn-hwp will be documented here.

## [0.1.0] - 2026-07-09

### Added

- Public Apache-2.0 open-source license posture.
- Public CI workflow for safety scan and non-real-fixture pytest suite.
- Public release checklist, security policy, contribution guide, citation metadata, and code of conduct.
- HWP/HWPX, DOCX, Markdown conversion/QA project framing for public OSS review.

### Notes

- Real HWP/HWPX fixture validation remains excluded from public CI because valid proprietary-format fixtures may not be redistributable.
